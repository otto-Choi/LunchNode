# 종료일 없는 운영

AX Node, Global, TMT 모두 `end_date = NULL`을 종료일 없음으로 사용합니다.
기존 시작일, 가입 계정, PIN, 세션, 신청, 확정 조는 보존합니다.
자동 편성은 한국 시각 전날 22시, 최종 마감은 당일 11시를 유지합니다.

달력에는 기존 운영 시작일부터 이번 달과 다음 두 달까지의 평일을 제공합니다.
예를 들어 12월에는 다음 해 2월까지 열리며, 1월이 되면 3월까지 자동으로 늘어납니다.
이는 사전 신청 범위이며 서비스 종료일이 아닙니다. 서버 조회와 예약 작업 모두 같은 DB 계산을 사용합니다.
PC는 월별로 이동하고, 모바일은 지난 날짜 카드를 생성하지 않습니다.
과거 확정 기록은 삭제하거나 기본값으로 다시 쓰지 않으며, 반복 만남 회피에도 계속 사용합니다.

## 설치

기존 AX/Global/TMT 및 Group Node 설치 후 연속 운영 마이그레이션을 적용합니다.
독립 SQL은 `supabase/continuous-operation.sql`이며 `python scripts/build-continuous-operation.py`로 재생성합니다.
과거 설치·이전 마이그레이션을 운영 DB에 다시 실행하는 대신 새 마이그레이션만 적용합니다.
Production에는 `OPERATION_END` 환경변수가 필요하지 않습니다. 해당 변수와 `lib/operation.ts`의 고정 날짜는 데모 전용입니다.
