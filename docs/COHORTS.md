# 35사번 Group Node 연동

첫 화면에서 사번(35/36)을 선택합니다. 기존 브라우저의 기본값은 36으로 유지합니다.

- 36사번: 기존 본부 코드·명단·계정·Lunch Node·Group Node를 유지합니다.
- 35사번: AX Node에서 `AX35` 코드 확인 후 이름과 숫자 6자리 PIN으로 직접 가입합니다. 동명이인은 구분 가능한 이름을 사용합니다.
- 35사번은 Group Node만 사용합니다. 화면의 Lunch 메뉴를 숨기고, 서버에서도 점심 신청·편성 복구·예약 작업을 차단합니다.
- 35 가입자는 기존 Lunch 명단에 추가되지 않습니다. 별도 `ax35_group_users/sessions/auth_buckets`에 저장하고 기존 계정과 PIN은 유지합니다.
- 코드는 서버의 `AX35_INVITE_CODE`로 설정하며, 브라우저 번들에 넣지 않습니다. 사번은 요청 헤더로 전달하지만 권한은 해당 사번의 전용 세션으로 확인합니다.

## 모임 공개 범위

- **전체**: 이용 가능한 모든 사번·본부에서 조회·참여합니다.
- **동기만**: 작성자와 같은 사번이면 본부가 달라도 조회·참여합니다.
- **우리 본부만**: 같은 사번·본부 안에서만 공개합니다. 기존 본부 전용 글이 35사번에 새로 공개되지 않습니다.

동기 범위는 작성자의 서버 계정으로 결정하며, 입력한 사번이나 작성자 정보로 변경할 수 없습니다.
목록·상세·참여·투표·댓글·참여자 추가 및 명단 조회에 같은 규칙을 적용합니다.
참여나 댓글을 남긴 사람을 제외하게 되는 범위 축소는 차단합니다. 기존 관리자의 통합 모임 관리 권한은 유지합니다.

## 미응답 표시 제거

Lunch의 미응답 건수 카드, 메뉴 알림 숫자, 달력 상태 문구·범례 및 프로필 기본 미응답 표시는 제거합니다.
저장된 unset을 불참으로 일괄 변경하지 않습니다. 결과 하단의 불참/미선택 구분은 기존 요청대로 유지합니다.
기존 조·참석 신청·매칭 이력은 수정하지 않습니다.

35 로그인·PIN 변경·로그아웃은 기존과 같은 PIN 해시와 계정/세션 잠금 규칙을 사용합니다.
예약 작업은 기존 점심 본부를 처리한 뒤 35의 만료 세션과 오래된 인증 제한 기록만 정리합니다.
