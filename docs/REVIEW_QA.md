# 코드리뷰와 QA · 2026-10-23

## 범위

Next.js 진입점과 화면, API·인증·운영자 권한, 본부 선택과 데이터 분리, 조 편성·참석 변경·마감, Supabase RPC·RLS·이름 변경 SQL, CI와 테스트 및 설정 문서를 검토했습니다. 실제 운영 DB에는 쓰기·초기화·마이그레이션을 실행하지 않습니다.

## 수정한 문제

| 문제 | 수정 및 검증 |
| --- | --- |
| 브라우저 저장소가 막히면 Global 로그인 후 AX로 되돌아갈 수 있음 | 현재 탭의 본부 선택을 메모리에도 보관. 저장소 차단 상태에서 Global 로그인·저장 브라우저 테스트 |
| 포커스 복귀·자동 갱신이 입력 중인 메뉴·참석 여부를 초기화 | 실제 저장된 선택이나 날짜·사용자가 바뀔 때만 편집값 초기화. 갱신 후 입력값 유지·날짜 변경 초기화 테스트 |
| 동시에 요청한 상태 응답이 역순으로 도착하면 오래된 데이터·401이 최신 화면을 덮어씀 | 마지막으로 시작한 조회만 화면에 반영. 오래된 성공·인증 실패 응답 각각의 브라우저 테스트 |
| 로그인 화면을 오래 열어둬 초대 코드 인증이 만료되면 재입력 경로가 없음 | 초대 코드 오류 시 코드 입력 화면으로 복귀. 재확인 후 로그인 테스트 |
| 운영자 복구가 예약 작업 권한으로 상태를 저장 | 운영자의 실제 세션으로 조회·저장. 인증 직후 세션이 해제되는 경합에서 변경 없음·401 테스트 |
| 첫날 수동 편성의 22시 이전 요청이 DB 오류로만 거절됨 | API에서도 시각을 검사해 명확한 409 반환·변경 없음 테스트. DB의 최종 검사 유지 |
| 테스트 일부가 운영 앱 대신 폐기된 HTML을 실행 | HTML 전용 테스트 제거. 실제 TypeScript 도메인과 현재 Next.js 브라우저 동작으로 검증 |
| SQL 생성기가 적용된 Global 마이그레이션 이력까지 덮어씀 | 설치기만 생성하도록 변경. 1회용 전환 SQL 생성기도 저장소에 포함 |

## 정리

과거 UI 시안 7개, 정적 HTML, browser-demo, ZIP, 미리보기 렌더러·생성기와 일회성 명단 스크립트, 오래된 테스트 결과·전달 메모를 제거했습니다. 사용 중인 Next.js 체험 모드는 유지합니다. README를 현재 설치·운영 구조 기준으로 다시 작성하고 클라이언트 API·본부 저장 처리를 `lib/client/`로 분리했습니다.

기존 마이그레이션과 실제 서비스 명단은 유지했습니다. 이번 앱 변경을 위한 추가 SQL·환경변수 입력은 필요하지 않습니다.

## 검증

- 도메인: 필수·선호 메뉴, 4인 우선, 참석자 누락·중복 방지, 과거 만남·성비·소속 혼합, 불참 출처, 날짜 전환.
- 인증·API: 명단 외 등록 차단, PIN 해시, 쿠키·세션, CSRF, 입력 제한, 계정·IP 제한, PIN 변경·세션 해제, 동시 저장 재시도, 운영자 권한.
- DB 통합: PostgreSQL 17에서 동시 저장, 마감 직전 경합, 확정 기록 보존, RLS·RPC 접근 제한, 본부 간 차단, 이름 변경 전후 계정·상태·객체 보존, 재실행 및 이전 구조 업그레이드.
- 브라우저: PC·모바일 각각 등록·로그인·저장·재접속·로그아웃, 날짜 카드와 일괄 참석·불참, 운영자 복구·재편성, 월 달력, 지난 날짜 처리, 13시 결과 전환, 미포함 명단·메뉴, 문의 링크·아이콘, 점검 화면, 저장소 차단·역순 응답·갱신 중 입력·초대 인증 만료.
- 타입 검사와 프로덕션 빌드. 실행별 통과·실패 및 증거는 GitHub Actions 로그·브라우저 보고서에서 확인합니다.

## 검증 한계와 후속 유지보수

운영 Supabase·Vercel 관리 권한을 사용하지 않으므로 운영 예약 호출의 실제 실행 기록·비밀값·운영 DB 백업은 이 QA에서 확인하지 않습니다. 테스트는 별도 DB와 테스트용 계정으로 진행합니다. 모바일은 Chromium 에뮬레이션이며 실제 iOS Safari·카카오 인앱 브라우저는 별도 기기 확인이 필요합니다.

대규모 화면 분리는 회귀 범위를 넓히므로 이번에는 요청·본부 선택만 분리했습니다. 조 편성은 인원 20명을 전제로 제한된 탐색을 수행하며 모든 배치의 수학적 최적해를 보장하지 않습니다.
