백엔드 개발 상태

현재 구현:
- 고정 명단 20명, 기본 메뉴 상관 없음, 12월 입사자 기본 불참
- scrypt PIN 인증, 서버 전용 해시 세션, 보안 쿠키, 시도 횟수 제한
- DB RPC 기반 원자적 등록/세션 생성과 PIN 변경/세션 폐기
- 신청 저장 CAS 재시도, DB 시각 마감 확인, 최종 기록 불변성
- 최초 편성/최종 확정 cron, 상태 요청의 누락 작업 복구
- 인증/입력/권한/DB 오류별 HTTP 응답, 명시적 데모 모드
- 새 DB용 baseline 및 14자리 순차 마이그레이션
- 실제 PostgreSQL 통합 테스트, Next.js 빌드/모바일·데스크톱 브라우저 CI

로컬 검증: 기존 규칙 11개 + 백엔드 10개 테스트 통과.
